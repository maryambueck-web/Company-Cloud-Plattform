# So würde ich die ERP-Störungen untersuchen

1. **Fehlerbild erfassen:** Zeitpunkt, Standort, Benutzer und Arbeitsschritt.
2. **Geschäftsablauf messen:** Anmeldung, Auftrag öffnen, speichern, drucken.
3. **Technische Werte vergleichen:** Netzwerk, Terminalserver, ERP, Datenbank und Storage.
4. **Hypothese prüfen:** Maßnahme passend zum nachgewiesenen Engpass.
5. **Pilot abnehmen:** Gleicher Ablauf bei vergleichbarer Last.

> Eine Migration allein beweist keine behobene ERP-Ursache.
